Hosting Guide
— GitHub Pages setup —
✦ Setup Steps
1.

Create GitHub Account

Go to github.com and sign up (free).

2.

Create Repository

Click + → New repository. Name it (e.g. karim-lara). Set to Public. Check "Add a README". Click Create.

3.

Upload Files

Click Add file → Upload files. Upload invite2.html and admin2.html. Commit.

4.

Enable GitHub Pages

Settings → Pages → Source → Deploy from branch → main / (root) → Save.

5.

Live URLs

https://USERNAME.github.io/REPO/admin2.html
https://USERNAME.github.io/REPO/invite2.html

6.

Create GitHub Token

Settings → Developer settings → Fine-grained tokens. Repository = your repo. Permissions → Contents: Read and write. Copy and paste token in Settings tab above.

7.

Upload Photos

Create a photos/ folder in your repo and upload images there. In Settings, use paths like photos/couple.jpg.

Repo name in Settings: Enter USERNAME/REPO in the GitHub Repository field so the admin knows where to push settings.

Deploy as Web App

Deploy → New deployment → Web app. Execute as: Me. Access: Anyone. Copy the URL and paste into Settings → Webhook URL.
